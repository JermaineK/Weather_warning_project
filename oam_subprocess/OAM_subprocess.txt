---
OAM / Spiral Companion Tools

This folder adds two light-touch helpers to bridge existing grid tables with
external OAM/spiral detectors. They avoid changing any maths; they just slice
and summarise.

1) extract_oam_patches.py   (Path A: targeted patches)
   - Input: grid table (CSV/Parquet) with time/lat/lon/ilat/ilon + vars.
   - Candidates: seeds file (time/lat/lon), prob/flag thresholds, or both.
   - Output:
       * metadata table (patch_id, time, lat/lon, patch_file, n_cells)
       * one .npz per patch with dense arrays for requested vars.
   - Example:
     python oam_subprocess/extract_oam_patches.py \
       --panel data/grid_train_gse_panel_targets.parquet \
       --seeds results/seedmaps/coral_sea_demo_union_byhour.parquet \
       --vars zeta,div,S,gka_knee_ratio,gka_score \
       --patch-radius-cells 2 \
       --prob-col prob_viable --prob-thr 0.2 \
       --max-patches 50000 \
       --out-meta results/oam_patches/meta.parquet \
       --out-dir results/oam_patches/patches

2) build_spiral_metafield.py (Path B: coarse hourly meta-map)
   - Input: grid table with time/lat/lon and variables (e.g., zeta/div/S).
   - Output: coarse per-hour map (Parquet/CSV) with mean/std/mean_abs per
     coarse lat/lon bin (default 1°).
   - Example:
     python oam_subprocess/build_spiral_metafield.py \
       --panel data/grid_train_gse_panel_targets.parquet \
       --vars zeta,div,S,pdrop_nd \
       --coarse-step-deg 1.0 \
       --out results/oam_meta/spiral_metafield.parquet

Notes
- No OAM math is implemented here; these scripts prepare inputs for your own
  spiral/knee detectors and provide coarse summaries to join back to GSE panels.
- Keep --structure-radius-km 0 when running proto_outcomes if you want maximum
  speed; track_points CSV can be heavy—use --points-format parquet to speed up.

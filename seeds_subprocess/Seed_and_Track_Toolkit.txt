---
Seed & Track Toolkit - Quick Guide
These scripts sit downstream of alerts. Feed them your viability-based alerts
(`prob_viable`, `alert_final`) and they build seed unions, patches, tracks, and
diagnostics for mapping.

Core tools (via seeds_tracks.py)
  from-alerts      -> proto seeds (union + starts) from alerts (CSV/Parquet, chunk-friendly)
  starts-vs-tracks -> seed starts -> patches -> track matching + lead stats
  proto-outcomes   -> link proto-tracks and label outcomes vs IBTrACS
  analyze          -> quick summaries of seed grids
  gse-tracks       -> track_seed_gse_states.py (G/S/E states + shear role, linked tracks + transitions)

Modern defaults (viability world)
  - prob-col  : prob_viable
  - flag-col  : alert_final (from denoise) or alert_base/any_alert
  - lon frame : -180..180
  - run-name  : used to prefix outputs in results/seedmaps

Examples
0) Seeds from alerts (viability)
python seeds_tracks.py from-alerts \
  --alerts results/alerts/alerts_coral_sea_demo_final.parquet \
  --prob-col prob_viable \
  --flag-col alert_final \
  --run-name coral_sea_demo \
  --normalize-lon "-180..180" \
  --area "-5,125,-35,175" \
  --out-dir results/seedmaps \
  --chunk-rows 400000 \
  --write-parquet

1) Seed starts vs tracks
python seeds_tracks.py starts-vs-tracks \
  --seeds results/seedmaps/coral_sea_demo_union_byhour.csv \
  --tracks data/tracks/tracks_subset.csv \
  --run-name coral_sea_demo \
  --radius-deg 2.5 \
  --time-tol-hours 18 \
  --min-run-hours 24 \
  --normalize-lon "-180..180" \
  --area "-5,125,-35,175" \
  --chunk-rows 400000 \
  --save-parquet \
  --out-dir results/seedmaps

2) Proto outcomes (optional)
python seeds_tracks.py proto-outcomes \
  --seeds results/seedmaps/coral_sea_demo_union_byhour.csv \
  --ibtracs data/tracks/tracks_subset.csv \
  --run-name coral_sea_demo \
  --normalize-lon "-180..180" \
  --lookahead-hours 120 \
  --chunk-rows 400000 \
  --out-dir results/seedmaps

3) Analyze seeds (quick QA)
python seeds_tracks.py analyze \
  --seeds results/seedmaps/coral_sea_demo_union_byhour.csv \
  --normalize-lon "-180..180" \
  --out-dir results/seedmaps

4) GSE seed state tracking (supportive vs destructive shear)
python seeds_tracks.py gse-tracks \
  --panel data/grid_train_gse_panel_states.parquet \
  --thr-file results/sweeps/viability_best_thresholds.parquet \
  --thr-lead 240 \
  --prob-col prob_viable \
  --flag-col alert_final \
  --direction-col zeta \
  --ibtracs data/tracks/tracks_subset.csv \
  --link-radius-km 90 \
  --chunk-rows 400000 \
  --run-name coral_sea_demo \
  --out-dir results/seedmaps \
  --write-parquet

Chunking
  - from-alerts: --chunk-rows for large CSV alerts (silent when 0/parquet).
  - starts-vs-tracks: --chunk-rows for CSV seeds/tracks (parquet ignored).
  - proto-outcomes: --chunk-rows for CSV seeds/features.
  - analyze: --chunk-rows for CSV inputs; parquet unaffected.
  - gse-tracks: --chunk-rows for CSV/parquet panels (filters first, then links seeds in-memory).
  - proto-outcomes: set --structure-radius-km 0 to skip expensive neighbour counts (uses haversine KDTree if installed when >0).
